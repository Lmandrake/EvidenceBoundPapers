# Seed essay (synthetic example)

*Written by hand before any agent ran. The extractor turns this into the first claim graph.*

Deep ocean heat content is only as trustworthy as the thermometers that measure it. Below
2000 m we rely on floats that are almost never recovered, and we correct them with one
adjustment for the whole fleet. I think each deep float should report its own calibration and
how sure we are of it. The pilot results say this is affordable for the floats we already fly.
