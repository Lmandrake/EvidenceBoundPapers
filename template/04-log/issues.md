# Issue ledger

Owned by the adjudicator. Reviewers do not write here.

**Respect `wont-fix`.** Do not re-raise a closed or won't-fix issue. Without this
rule the loop churns forever, re-litigating the same objection each round while
producing the appearance of activity.

You cannot `wont-fix` an enforcer finding.

## Format

```
### ISS-0nn
- taxonomy: F4.2
- source: reviewer-skeptic R-03 | enforcer E-07
- locus: GAP-04 / §3.2
- claim: <what is wrong>
- status: open | closed | wont-fix
- rationale: <required for wont-fix>
- closed-by: <iteration n, how>
- raised: <ISO date>
```
