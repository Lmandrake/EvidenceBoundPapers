# Citable corpus

**FICTIONAL.** Every source below is invented for this example. The authors, journals and
numbers do not exist; the texts in `corpus-text/` were written to be quoted from.

Closed corpus: a citation is legal only if its key appears in the table. A source with no cached
full text (`span-verifiable: no`) is still citable but caps the claims citing it at `Suggestive`.

## Config

```
recency-window-years: 5          # E-12. Window base year 2026 -> 2021-2026.
advocacy-wordlist: Meridian Ocean Institute, Tidewater Basin Authority, Halcyon Foundation
identifier-tokens: DeepProfiler-2, Abyss-6K   # E-06: instrument names whose digits are not statistics
```
